# AHK-Replay

通用「操作录制 + 循环回放」工具（AutoHotkey v2）。在任何网页/软件里像平时一样操作一遍，
工具记录真实的点击坐标、滚轮与按键，之后可无限次循环回放——对任何应用通用，
因为回放的就是真人级的系统输入事件。

## 快速开始

1. 双击 `start.bat`（或直接双击 `AHK-Replay.ahk`）——托盘出现绿色 H 图标
2. 打开目标网页/软件，按 **F2** 开始录制（左上角出现「● 录制中」）
3. 像平时一样完整操作一遍（点击、滚动、Ctrl+V 粘贴、Enter 等）
4. 再按 **F2** 结束 → 给录制起个名字 → 输入回放次数 → 自动循环
5. **F12** 随时急停

## 快捷键

| 键 | 功能 |
|---|---|
| F2 | 开始/结束录制（结束自动存入 `recordings/` 并询问回放次数） |
| F4 | 回放最近一次录制 |
| F5 | 从 `recordings/` 文件夹挑选任意历史录制回放 |
| F12 | 急停：回放中立即停止；平时按下则退出脚本 |

## 机制说明

- **剪贴板快照**：录制时每次 Ctrl+V 都会连同当时的剪贴板内容一起存档；
  回放时自动还原再粘贴——录什么贴什么，不依赖任何外部文件
- **绝对坐标回放**：录制开始后，目标窗口的位置和缩放不要变（保持最大化最稳）
- **节奏保真**：按录制的原始节奏回放；超过 2.5 秒的发呆会压缩到 2.5 秒，
  每轮之间休息 `INTER_LOOP_MS`（脚本顶部可改，默认 3 秒）
- **循环要点**：录制的最后一步要让页面回到"能操作下一条"的状态
  （例如聊天类页面点「下一个」，或列表页向下滚动），否则每轮都重复同一条

## 注意事项

- 回放期间不要动鼠标键盘
- 网站类操作请遵守目标网站服务条款，控制频率与总量，注意账号安全
- 录制文件是纯文本（`recordings/*.ahkr`），可用记事本查看/微调坐标后重放

## 文件

```
AHK-Replay.ahk    主脚本
start.bat         双击启动
recordings/       录制存档（自动生成）
ahk-replay.log    运行日志（自动生成）
```
